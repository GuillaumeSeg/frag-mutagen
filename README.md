# frag-mutagen

A generative fragment shader exploring the irreversible decay of a structured grid into pure chaos.

## Concept
**BASE → LOW → MEDIUM → HIGH → MUTATED**

Each tile in the grid follows its own timeline, progressing through five distinct states. 
From order to disorder, from structure to explosion.
*We were ordered, and we become chaotic.*


## Usage
1. Open `shaders/main.frag` in VS Code.
2. Ensure the **glsl-canvas** extension is installed.
3. Run `Cmd+Shift+P` → `Show glslCanvas`.
4. Hit `Cmd+S` to see live updates.
